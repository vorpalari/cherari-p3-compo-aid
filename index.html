Remember!
1Always repeat the question back to yourself once. Students always forget the question after talking!
2If you forget the question, say: Sorry teacher, can you repeat the question? Thank you.
3If you need time to think before answering, say: I need some time to think before answering, thank you Teacher.
4If you need to restart, say: Teacher, I would like to restart again.
